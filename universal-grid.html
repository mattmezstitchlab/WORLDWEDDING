THE UNIVERSAL GRID

Un même langage peut être lu par la position, le signe, la forme, la couleur, l'intensité, le rythme et le nombre. Cette page transforme l'idée en prototype : une grammaire graphique configurable, progressive et réversible.

THE LANGUAGE

Les noms des points viennent de techniques réelles de broderie. Les significations ci-dessous sont des conventions proposées pour WWC : elles doivent être apprises comme une légende, puis rester stables. Une couleur n'est jamais porteuse du sens à elle seule.

×
Point de croix

Convention WWC : présence / expérience.

╱
Point lancé

Convention WWC : direction / intention / mouvement.

◌
Point de chaînette

Convention WWC : relation continue / lien.

●
Point de nœud

Convention WWC : détail / souvenir / attention.

DEFINE THE SIGN

Le langage doit pouvoir évoluer sans changer de grille. Ici, chaque signe reçoit une définition, une couleur d'appui, une intensité et une cadence. Le moteur conserve la même cellule : seul son état change.

COMPOSE A MESSAGE

Le message original reste la source. La grille est une représentation symbolique qui peut ensuite être rendue visuellement, vocalement, tactilement ou par balayage assistif.

SIGNATURE VISUELLE
Prototype : cette représentation n'est pas une signature électronique juridiquement qualifiée et ne remplace pas les exigences légales d'un acte.
ACCESSIBILITÉ PAR CONCEPTION. La même donnée pourra être sélectionnée par toucher, regard, balayage, switch, voix ou interface adaptée. Pour une utilisation médicale, palliative, successorale ou contractuelle réelle, le système devra être validé avec des spécialistes de l'accessibilité, des utilisateurs concernés et, selon le cas, des professionnels compétents. Il ne faut pas supposer qu'un symbole est universel sans l'avoir testé et documenté.
