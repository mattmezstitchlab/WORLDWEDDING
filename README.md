# WORLDWEDDING

## Produit — état actuel

WORLDWEDDING est organisé autour de quatre portes principales : **WORLD**, **365 ÉDITIONS**, **MY WEDDING** et **MIRRORS**.

- `destinations.js` est la source de vérité géographique des 365 éditions.
- `my-wedding.html` transforme une destination en premier scénario de mariage : saison, invités, budget et style.
- Le Mirror est enregistré localement dans le navigateur (`localStorage`) dans cette version.
- Les contenus de lieux, professionnels, prix, disponibilités et obligations ne sont pas encore présentés comme des données vérifiées : ils devront être branchés à des sources réelles et versionnées.
- `universal-grid.html`, `pattern-lab.html`, `agents.html` et `systematlas.html` restent des laboratoires / couches d'architecture, pas des portes principales du produit.

### Flux cible

`WORLD → DESTINATION → EDITION → 24H → MIRROR → MY WEDDING`
